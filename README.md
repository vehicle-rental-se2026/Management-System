# Vehicle Rental Management System

## Description
A Java-based Vehicle Rental Management System developed using Swing and Maven.
The system allows managers to manage vehicle rentals, returns, billing, vehicle types, and rental reminders.

## Features
- Manager Login
- View Vehicles
- Rent Vehicles
- Return Vehicles
- Billing Calculation
- Vehicle Types
- Rental Reminder
- Strategy Design Pattern
- Observer Design Pattern

## Technologies Used
- Java
- Swing
- Maven
- JUnit 5
- Cucumber
- JaCoCo

## Project Structure
- billing
- domain
- enums
- notification
- observer
- presentation
- repository
- service
- strategy
- vehicletype

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Build the project using Maven.
4. Run the `Main` class.
